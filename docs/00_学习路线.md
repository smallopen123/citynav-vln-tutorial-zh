# 00｜学习路线：从“看懂名词”到“跑通实验”

## 你真正需要建立的心智模型

VLN（Vision-and-Language Navigation，视觉—语言导航）不是一次预测。它是一个持续交互过程：智能体收到语言任务，在每个时刻观察环境，根据历史决定动作，再从新位置获取下一帧观测。

记住这一条主线即可：

```text
语言指令 I + 当前观测 O_t + 历史 H_t + 位姿 P_t
                  ↓ 模型/策略 π
             动作 A_t 或地图目标 G_t
                  ↓ 环境执行
       新观测 O_(t+1)、新位姿 P_(t+1)、新历史
```

CityNav 的特殊之处是把智能体放到大尺度、真实城市三维环境中的无人机视角。目标可能很远，单帧相机根本看不到，因此既要理解语言和地标，也要做长距离定位、规划、逐步控制和正确停止。

## 三层学习目标

### 第一层：会解释

你应能用自己的话解释 episode、step、observation、action、trajectory、goal、STOP、SR 和 SPL。完成第 1、3、5 章即可。

### 第二层：会运行和排错

你应能修改教学 episode，观察策略如何改变；拿到真实 JSON 后，知道指令、目标、轨迹和划分存在哪里。完成第 2 章并运行两个 example。

### 第三层：会研究

你应能把失败归因到语言 grounding、全局定位、长期记忆、局部控制或停止判断中的某一层，并选择合适方法改进。完成第 4、6、7 章。

## 一天速学安排

| 时间 | 内容 | 必须产生的输出 |
|---|---|---|
| 45 分钟 | 第 1 章 + 运行 toy episode | 手画一遍 VLN 闭环 |
| 60 分钟 | 第 2、3 章 | 能口述两个相邻 step |
| 45 分钟 | 第 4 章 | 解释 GSM 为什么不是普通图片 |
| 30 分钟 | 第 5 章 + 改 toy JSON | 举出 OSR=1、SR=0 的例子 |
| 60 分钟 | 第 6、7 章 | 写出自己的复现路线和风险清单 |

## 学习时不要混在一起的三类东西

1. **数据集**：规定任务、数据、划分和评价协议，例如 CityNav。
2. **环境/模拟器**：执行动作并返回 RGB-D、位姿和碰撞等状态。
3. **方法/模型**：根据输入做决策，例如 CityNav 原始基线、FlightGPT 或后续方法。

同一个数据集可以测试多个模型；同一个模型也可能在多个数据集上验证。看到一张结果表时，必须同时确认数据划分、成功半径、模型输入、是否使用额外地图/模型，以及评测代码版本。
